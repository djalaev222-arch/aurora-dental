# Аврора Дентал — сайт стоматологической клиники

Одностраничный сайт клиники: React 19 + Vite + Tailwind CSS v4 + Motion на клиенте,
Express API для формы записи на приём.

## Стек

- **client/** — React + Vite (JavaScript), Tailwind CSS v4, Motion (Framer Motion),
  React Hook Form, Phosphor Icons.
- **server/** — Node.js + Express: отдаёт доступное время по врачу/дате и принимает заявки на запись.

## Быстрый старт

```bash
npm run install:all   # установит зависимости client/ и server/
cp server/.env.example server/.env   # при необходимости — настройте SMTP
npm run dev            # поднимет клиент (5173) и сервер (4000) одновременно
```

Откройте http://localhost:5173.

Отдельно:

```bash
npm run dev:client   # только фронтенд
npm run dev:server   # только API
```

## Форма записи

- `GET /api/availability?doctorId=&date=` — свободное время на дату (детерминированная заглушка без БД).
- `POST /api/booking` — валидирует и сохраняет заявку в `server/data/bookings.json`.
  Если в `server/.env` заданы `SMTP_HOST/SMTP_USER/SMTP_PASS`, заявка также уходит
  письмом на `CLINIC_NOTIFY_EMAIL`. Без SMTP заявки просто сохраняются локально —
  это нормально для разработки.

## Важно перед запуском в продакшн

1. **Фотографии — временные плейсхолдеры.** Все изображения (герой, врачи, отзывы,
   слайдеры «до/после») сейчас подтягиваются с `picsum.photos` по сиду —
   это случайные стоковые фото, не имеющие отношения к стоматологии. Их нужно
   заменить на настоящие фотографии клиники и (обязательно, с согласия пациентов)
   реальные снимки «до/после» — выдавать случайные фото за результаты лечения
   недопустимо ни с этической, ни с юридической точки зрения. Заодно замена даст
   заметный прирост скорости загрузки: `picsum.photos` не оптимизирован под
   продакшн-трафик и добавляет заметную задержку на первую отрисовку (LCP).
2. **Лицензия, адрес, телефон, e-mail, карта** в `client/src/data/content.js` —
   демонстрационные, замените на настоящие реквизиты клиники.
3. **SMTP** — без настройки почты заявки не будут никуда уходить, только
   сохраняться в файл. Для продакшна лучше подключить транзакционный
   email-сервис или CRM вместо nodemailer + файла.
4. Перед деплоем клиента задайте прокси или переменную окружения на реальный
   адрес API вместо `localhost:4000`.

## Структура

```
client/src/
  components/   — по одному разделу лендинга на папку
  data/content.js — весь текстовый контент клиники в одном месте
  hooks/        — useAvailability (загрузка свободного времени)
  lib/          — форматирование цен
server/
  routes/booking.js — валидация и приём заявок
  lib/          — доступность слотов, каталог услуг/врачей, отправка письма, хранилище
```
